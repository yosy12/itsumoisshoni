# ホーム画面（サンプル体験） E2Eテスト仕様書

生成日: 2026-08-02
対象画面: `HomePage`（未登録時のトップ画面、URLは `/` 固定・screen state で切替）
権限レベル: 不要（ログインなし）

---

## ユーザーゴール

1. 登録前にサンプルのコで「いつも一緒」の雰囲気を体験できる
2. 複数のサンプルペットを見比べられる
3. 気に入ったら自分のペット登録に進める

---

## テスト環境

```yaml
URL: baseURL相対パス "/" （process.env.BASE_URLで切替可能・localhostハードコード禁止）
認証: 不要
前提条件: localStorage が空であること（未登録状態）
```

---

## E2Eテスト項目一覧（5項目）

| ID | テスト項目 | フロー内容 | 期待結果 |
|----|----------|-----------|---------|
| E2E-HOME-001 | 初期表示 | localStorage空の状態で `/` にアクセス | ペット写真・名前・時間帯ラベル・お世話アクションボタン・登録CTAが表示される |
| E2E-HOME-002 | サンプルペット切り替え | ‹ / › ボタンを操作 | ペット写真・名前・性格が別のサンプルペットに切り替わる |
| E2E-HOME-003 | お世話アクションフロー | アクションボタンをタップ | セリフバブルが表示され、その中にメッセージ文言が表示される |
| E2E-HOME-004 | 登録導線 | 「🐾 自分のコを登録する」をタップ | 登録画面（名前入力欄）に遷移する |
| E2E-HOME-005 | 外部相談リンク | My Treasury ARFリンクのhref/target属性を確認 | `target="_blank"` かつ正しいURLが設定されている |
