# マイペット画面 E2Eテスト仕様書

生成日: 2026-08-02
対象画面: `PetHomePage`（登録済みペットとの日常画面、screen state で切替）
権限レベル: 不要（ログインなし）

---

## ユーザーゴール

1. 登録した自分のペットと日常的にふれあえる
2. プレミアム機能（話しかける/アルバム/雰囲気）の存在を知ることができる
3. 複数のペットを登録している場合、切り替えたり追加登録できる

---

## テスト環境

```yaml
URL: baseURL相対パス "/" （localStorageにペット登録済み状態を設定してからアクセス）
認証: 不要
前提条件: 各テスト開始時に localStorage に `itsumoisshoni_state` をセットしてペット登録済み状態を再現する
```

---

## E2Eテスト項目一覧（5項目）

| ID | テスト項目 | フロー内容 | 期待結果 |
|----|----------|-----------|---------|
| E2E-PET-001 | 初期表示 | ペット登録済み状態で `/` にアクセス | 登録したペットの名前・写真・お世話アクションボタンが表示される |
| E2E-PET-002 | お世話アクションフロー | アクションボタンをタップ | セリフバブルが表示され、メッセージ文言が表示される |
| E2E-PET-003 | プレミアム機能紹介フロー | プレミアム機能（話しかける等）をタップ → モーダル表示 → 閉じる | モーダルに機能説明が表示され、「とじる」で閉じられる |
| E2E-PET-004 | ペット切り替えフロー | 複数ペット登録状態で切り替えボタンをタップ → 一覧表示 → 別のペットを選択 | 選択したペットの名前・写真に切り替わる |
| E2E-PET-005 | ペット追加導線 | 「あたらしいコを追加」をタップ | 登録画面に遷移する |
