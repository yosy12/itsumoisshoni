# 登録画面 E2Eテスト仕様書

生成日: 2026-08-02
対象画面: `RegisterPage`（ペット登録フォーム、screen state で切替）
権限レベル: 不要（ログインなし）

---

## ユーザーゴール

1. 自分のペットの情報（名前・種類・ステータス・性格・好きなもの・写真）を登録できる
2. 登録すると自分のペットとの画面（マイペット画面）に進める
3. 途中でやめて前の画面に戻れる

---

## テスト環境

```yaml
URL: baseURL相対パス "/" 経由でHOME→登録導線をタップして遷移（直接URLなし）
認証: 不要
前提条件: localStorage は各テスト開始時にクリアする（新規登録前提のテストのため）
```

---

## E2Eテスト項目一覧（6項目）

| ID | テスト項目 | フロー内容 | 期待結果 |
|----|----------|-----------|---------|
| E2E-REG-001 | 種類選択フロー | ホームから登録画面へ → 種類ボタン（いぬ/ねこ/ことり/その他）をタップ | タップした種類ボタンが選択状態（強調表示）になる |
| E2E-REG-002 | ステータス選択フロー | ステータス（お空にいるコ/今いるコ/架空のコ）を選択 | 選択したステータスが選択状態になる |
| E2E-REG-003 | 名前未入力時のボタン無効化 | 名前欄を空のまま「登録する」ボタンの状態を確認 | 登録ボタンが disabled になっている |
| E2E-REG-004 | 登録完了フロー | 名前・性格・好きなものを入力 → 種類/ステータス選択 → 「登録する」をタップ | マイペット画面に遷移し、入力した名前・性格がそのまま表示される |
| E2E-REG-005 | もどる導線（未登録時） | 未登録状態で「‹ もどる」をタップ | ホーム画面（サンプル体験）に戻る |
| E2E-REG-006 | 写真アップロードフロー | 写真エリアをタップ → 画像ファイルを選択 | 選択した画像がプレビューとして円形写真エリアに表示される |
